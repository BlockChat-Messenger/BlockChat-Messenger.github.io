Особенности BlockChat

Уникальные возможности нашего P2P мессенджера

Система BlockChat ID

Уникальные идентификаторы для каждого пользователя. Создайте свой ID один раз и используйте его для всех чатов.

Быстрое подключение

Присоединяйтесь к чатам по 6-значным кодам. Создавайте чаты и делитесь кодом с собеседниками.

Мгновенная доставка

Сообщения доставляются мгновенно благодаря прямой связи между пользователями после установки соединения.

Поддержка Markdown

Форматируйте текст легко и быстро! BlockChat поддерживает Markdown-разметку.

Простой интерфейс

Интуитивно понятный интерфейс позволяет легко создать BlockChat ID, настроить чаты и начать общение.

Кроссплатформенность

Доступно для Windows, Linux и macOS. Общайтесь с пользователями разных ОС через единую систему BlockChat ID.

Как подключиться

Простой процесс установки защищенного соединения через BlockChat ID

1

Создайте BlockChat ID

Зарегистрируйтесь в системе с уникальным никнеймом и получите персональный ID

2

Создайте или присоединитесь

Создайте новый чат и получите 6-значный код, или введите код существующего чата

3

Установите P2P соединение

Система автоматически установит соединение через BlockChat ID

4

Начните общение

Наслаждайтесь безопасным общением! Сообщения идут напрямую между устройствами.
